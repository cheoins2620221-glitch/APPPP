# ScreenTime Guardian (Android, Kotlin) — v0.3

자녀 기기의 앱 사용시간을 관리하는 앱. Kaspersky Safe Kids / Google Family Link와 동일한 원리(AccessibilityService + Overlay)로 동작합니다.

## v0.3에서 추가된 것

**시간 은행 확장**
- 하루 최대 인출(사용) 한도 추가 — 저축이 아무리 많아도 하루에 부모가 정한 한도(기본 3시간, 2~4시간 권장) 이상은 못 꺼내 씀
- 대출 기능 — 하루 최대 1시간까지 대출 가능, 대출금은 즉시 저축 잔액에 반영되어 바로 사용 가능
- 대출 상환 방식 2가지
  - **미리쓰기제(PREPAY)**: 대출받은 다음날부터, 그날 저축되는(아낀) 시간을 대출 상환에 먼저 사용. 다 못 갚으면 저축 잔액에서 강제 차감
  - **기한제(DEADLINE)**: 7일 안에 안 갚으면 이자(기본 20%)가 붙고 기한이 다시 7일 연장됨(복리). 저축 잔액으로 언제든 수동 상환 가능

**타임 리워드**
- 저축 상한을 넘는 잔여시간은 자동으로 리워드 포인트(1분=1포인트)로 전환
- 리워드 ↔ 저축시간 상호 환전 기능, 환전할 때마다 세금(기본 10%) 부과
- (실제 기프티콘 등 혜택 카탈로그 연동은 아직 없음 — 포인트 잔액 관리까지만 구현됨)

**초기설정 보호(PIN)**
- 부모가 4자리 PIN을 설정하면, 이후 은행 설정 변경 / 앱별 한도 추가·삭제 시마다 PIN 입력을 요구
- PIN을 비워서 저장하면 잠금 해제됨

## 기존 기능 (v0.2부터)

- 앱별 스크린타임(하루 한도, 그레이스 피리어드)
- 그레이스 피리어드: 한도 도달 시 즉시 차단이 아니라 카운트다운 오버레이 → 홈 이동 + 차단 오버레이. 재실행 시마다 반복 차단
- 권한 바로가기 버튼(접근성, 오버레이)

## 실기기/에뮬레이터 테스트 순서

1. 앱 설치 후 실행 → 메인 화면에서 접근성/오버레이 권한 켜기
2. "3. 시간 은행 설정"에서 저축 상한, 하루 인출 한도, 시간대, 대출 상환방식, 이자율, 환전세를 원하는 값으로 저장
3. "4. 대출"에서 "1시간 대출받기" 눌러보면 "2. 시간 은행 현황"의 저축 잔액이 즉시 늘어나는지 확인
4. "5. 리워드 환전"에서 저축 시간 일부를 리워드로, 다시 리워드를 시간으로 바꿔보며 환전세가 정확히 반영되는지 확인
5. "6. 설정 잠금"에서 PIN을 설정한 뒤, 다시 은행 설정을 저장하거나 앱을 추가/삭제하려고 하면 PIN 입력창이 뜨는지 확인
6. "7. 앱별 스크린타임 추가"에서 테스트 앱을 짧은 한도(1~2분)로 등록해서 그레이스 → 차단 흐름 확인
7. 대출/리워드 자동 정산(다음날 이자·차감·저축 전환)은 기기 날짜를 하루 넘겨서 앱을 다시 열면 `settleIfNeeded()`가 실행되며 반영됩니다

## 아직 안 된 것 / 알려진 한계

- 부모-자녀 기기 간 원격 동기화는 없음 (자녀 기기 로컬에서 부모가 직접 설정)
- 자정 정산은 앱이 켜져 있을 때만 체크됨 — `WorkManager`로 백그라운드 정산 예약 필요
- 리워드 포인트를 실제 기프티콘 등으로 교환하는 카탈로그/연동은 없음 (포인트 잔액만 관리)
- PIN은 평문으로 저장됨 — 실제 배포 시에는 해시 저장 필요
- 기기 시간 조작으로 대출 기한/적립시간대를 우회할 수 있음 — 서버/NTP 시간 검증 필요
- DB 스키마가 바뀌어서(v1→v2) 기존에 설치했던 앱이 있다면 데이터가 초기화됩니다(테스트 단계라 허용)
